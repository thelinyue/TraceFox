# TraceFox 0.0.2

本版本进一步完善 Windows 桌面集成、规则管理和离线报告，提升大体积诊断报告的加载与分发效率。

- 增加开机启动设置和桌面通知，完善任务监控与窗口交互。
- 优化规则编辑器的目录、分组、排序和跨组移动，保留规则引用关系。
- 增强启动、恢复和异常关机事实分析，避免对证据不足的事件作过度判断。
- 完善日志提取、SMART 与磁盘信息展示，并压缩离线报告内嵌数据以减小文件体积。
- 为压缩报告补充格式校验、加载失败提示和大数据量浏览器回归测试。

## 安装

下载并运行 `TraceFox-0.0.2-setup.exe`，按当前用户安装，无需管理员权限。默认目录为 `%LOCALAPPDATA%\Programs\TraceFox`。

升级不会覆盖已有规则和用户设置。解压日志和 HTML 报告仍位于原诊断包旁的同名目录，样本与诊断数据不随安装包分发。

## 使用边界

关键词、SMART 和启动事实用于辅助人工判断，不自动作出故障结论。离线报告的压缩数据需要最新版 Edge 或 Chrome 打开。不支持自动更新。安装包未做代码签名，Windows 可能显示未知发布者。
