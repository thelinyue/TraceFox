# TraceFox 0.0.1

首个正式版本，面向 Windows x64 的本地 NAS 诊断信息提取工具。

- 导入 UGOS / UGOS Pro TGZ 诊断包，支持包内 gzip 轮转日志、目录监控及任务取消、重试。
- 生成可离线浏览的 HTML 报告，展示系统信息、存储池、硬盘 SMART、关键词证据和时间线。
- 提供规则编辑、导入导出、默认规则还原与 WebDAV 规则同步。
- 显示分析耗时，完善磁盘原始字段和报告展示。

## 安装

下载并运行 `TraceFox-0.0.1-setup.exe`，按当前用户安装，无需管理员权限。默认目录为 `%LOCALAPPDATA%\Programs\TraceFox`。

规则保存在程序旁的 `assets\default-rules.json`。还原默认规则先进入草稿，保存全部后生效；WebDAV 下载和接受远端同步会直接保存。升级保留已有规则，卸载保留规则和用户设置。已有开发版用户可先导出规则，再在正式版导入。

解压日志和 HTML 报告位于原诊断包旁的同名目录。样本与诊断数据不随安装包分发。

## 使用边界

关键词与 SMART 展示用于辅助人工判断，不自动作出故障结论。不支持自动更新。安装包未做代码签名，Windows 可能显示未知发布者。
